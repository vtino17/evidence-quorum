# Contributing

Thank you for helping improve completion verification for agent workflows.

1. Open an issue for substantial protocol changes.
2. Create a focused branch.
3. Add tests for policy behavior and adversarial cases.
4. Run `pnpm check`.
5. Open a pull request explaining the behavior and trust assumptions.

Keep public interfaces and documentation in international English. Avoid adding network calls to the core package; deterministic, local audits are a design constraint.
